# 🚀 快速入门

## 第一步：调整设置

- ☑ **允许两队重复英雄**
    - 开启：两队可选择相同英雄
    - 关闭：英雄唯一分配

- ☑ **自动分配英雄**
    - 开启：系统自动分配
    - 关闭：只分配位置，玩家自选英雄

## 第二步：配置英雄池

### 添加自定义英雄

- 格式：位置-英雄名称
- 示例： T-莱因哈特

### 管理操作

- **添加英雄**：输入格式正确的英雄名称
- **重置英雄池**：恢复默认英雄列表
- **移除英雄**：点击英雄项右侧的 × 按钮

## 第三步：添加玩家

### 方法A：手动添加

1. 在 "玩家名称" 输入框填写游戏ID
2. 选择实力等级：
    - ⭐⭐⭐ = 神
    - ⭐⭐ = 蛆
    - ⭐ = 蛆神
3. 选择位置偏好：
    - 🛡️ 坦克
    - ⚔️ 输出
    - 🩹 支援
    - 任意位置
4. 点击 "添加玩家" 确认

### 方法B：快速选择

- 调整玩家的偏好位置
- 点击玩家添加至已选中玩家

## 第四步：开始分配

点击 "🎲 开始分配" 按钮，系统将：

1. 自动平衡两队实力
2. 智能分配英雄角色
3. 生成详细对阵表

# 🎪 高级功能

## 内幕彩蛋系统

触发界面隐藏功能打开内幕面板：

### 🔥 敌对群友设置

**功能说明**  
将特定玩家设置为敌对关系，系统会尽量将他们分配到对立队伍。

**操作步骤**

1. 在 "选择玩家1" 下拉菜单选择第一个玩家
2. 在 "选择玩家2" 下拉菜单选择第二个玩家
3. 点击 "确认" 按钮建立敌对关系
4. 在敌对列表中查看和管理现有关系

### ⭐ 专属英雄绑定

**功能说明**  
为玩家指定专属英雄，分配时优先考虑绑定的英雄选择。

**操作步骤**

1. 在 "选择玩家" 下拉菜单选择目标玩家
2. 选择要绑定的英雄
3. 点击 "确认" 建立绑定

**管理功能**

- 查看所有专属设置
- 移除单个绑定
- 一键清空所有绑定关系
